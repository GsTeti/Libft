# Libft - Recriação de Funções da Biblioteca Padrão em C

Este repositório contém a minha implementação da **libft**, um projeto focado em recriar funções essenciais da biblioteca padrão do C (`libc`). O objetivo principal é consolidar conceitos fundamentais de lógica de programação de baixo nível, manipulação de ponteiros, strings e gerenciamento manual de memória.

## Funções Implementadas

O repositório conta com as seguintes funções desenvolvidas e estruturadas:

### Verificação e Conversão de Caracteres
*   `ft_isalpha` / `ft_isdigit` / `ft_isalnum` / `ft_isascii` / `ft_isprint` — Checagem de tipos de caracteres.
*   `ft_toupper` / `ft_tolower` — Conversão de caixa alta e baixa.

### Manipulação de Strings
*   `ft_strlen` — Contagem de comprimento de string.
*   `ft_strchr` / `ft_strrchr` — Localização de caracteres em strings.
*   `ft_strncmp` — Comparação de strings com limite de caracteres.
*   `ft_strlcpy` / `ft_strlcat` — Cópia e concatenação seguras de strings.
*   `ft_strdup` — Duplicação de string com alocação dinâmica.

### Manipulação e Gerenciamento de Memória
*   `ft_bzero` / `ft_memset` — Inicialização e preenchimento de blocos de memória.
*   `ft_memcpy` / `ft_memmove` — Cópia de blocos de memória (tratando ou não sobreposição).
*   `ft_memchr` / `ft_memcmp` — Localização e comparação de blocos de memória.

## Estrutura do Projeto

*   **`*.c`**: Arquivos de código-fonte contendo a lógica de cada função individual.
*   **`libft.h`**: Arquivo de cabeçalho (header) contendo os protótipos de todas as funções e as inclusões necessárias.
